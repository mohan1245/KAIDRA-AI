Welcome to our studio

This page is a stand-in for any real website — a gym, salon, clinic, or any other business. It includes the Kaidra AI assistant as a floating chat widget.

Look at the bottom-right corner of this page. The floating chat bubble is provided by Kaidra AI. Click it to try the assistant.

This is all it takes to add the Kaidra chat bubble: 
<script
  src="https://kaidra-ai.onrender.com/embed.js"
  data-api-base="https://kaidra-ai.onrender.com"
></script>

On a real external website, the customer only needs to add the same script to their HTML.

The src loads the Kaidra floating widget, while data-api-base tells the widget where the Kaidra backend is running.
