Welcome to our studio

This page is a stand-in for any real website — a gym, salon, clinic, whatever. It has nothing to do with Kaidra's own code; it only includes one script tag, shown below, which is all a real customer would need to add.

Look at the bottom-right corner of this page — that chat bubble was added by a single line of HTML. Click it to try the assistant.

This is all it took to add the chat bubble to this page: 
<script src="/widget/embed.js"></script>

On a real external website, you'd point data-api-base at your deployed server's URL, since the script won't be loaded from the same origin as your Kaidra server:

<script
  src="https://your-app.onrender.com/widget/embed.js"
  data-api-base="https://your-app.onrender.com">
</script>
